# Test Mode

## Ziel

Ein erster Durchlauf soll reviewbar sein, nicht maximal umfangreich.

## Ausgabeform

Für jeden Block:
- Evidenz
- Interpretation
- vorgeschlagene Maestro-Objekte
- Kategorie / Account / Typ soweit relevant
- Dauer-Modus
- Begründung

## Disziplin

- keine künstlichen Tasks
- keine erfundenen Activities
- abgeleitete Zeit nur als TimeUnit
