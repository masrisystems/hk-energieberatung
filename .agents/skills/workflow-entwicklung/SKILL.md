# workflow-entwicklung

## Ablauf

1. **Agentengrenze prüfen:** „Mechanik vor Agentenanweisung" aus
   `.agent/professions/konstrukteur.md` anwenden. Nur der danach verbleibende agentische
   Anteil wird als Workflow ausgefüllt.

2. **Template laden:** `.agent/templates/workflow.md`

3. **Zweck in einem Satz:** Was löst dieser Workflow aus?

4. **Ablauf schreiben:**
   - Schritte benennen, was zu tun ist
   - Skill-Verweise nur als Verweise — Mechanik bleibt im jeweiligen SKILL.md

5. **Schicht-1-Prinzipien** aus `.agent/professions/konstrukteur.md` anwenden.
